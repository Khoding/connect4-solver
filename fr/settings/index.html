Diagramme de régime permanent en mode apprentissage

Le mode résolveur affiche toujours le petit diagramme. En mode apprentissage, choisis où il apparaît (ou non) : la petite carte latérale, les marqueurs sur le plateau principal, ou les deux. « Désactivé » conserve les conseils progressifs.
